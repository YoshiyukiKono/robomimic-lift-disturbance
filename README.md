# 学習済みロボット制御モデルの外乱応答の観察

robomimicの学習済みモデルを用いて、シミュレーション上のロボットアームによる物体の持ち上げを実行し、物体に加える外力によって動作がどう変わるかを観察するプロジェクトです。

モデルの追加学習は行わず、推論のみを使用します。

## 目的

学習済みモデルが通常の条件でタスクを実行できることを確認したうえで、物体に外力を加えた場合の動作を調べます。

主な問いは次の2点です。

1. 動作開始後に物体が移動しても、持ち上げを達成できるか。
2. 物体が台から落下した場合、ロボットはどのような動作を続けるか。

本実験は、限られた条件での探索的な観察です。モデルの一般的な成功率や、実機での性能を評価するものではありません。

## 使用するAIとシミュレーション

| 項目 | 内容 |
|---|---|
| タスク | 台上の立方体の持ち上げ（Lift） |
| ロボット | Pandaロボットアーム |
| 学習済みモデル | robomimic v0.1 Lift PH low_dim BC-RNN |
| 学習方法 | 人の操作例を用いた模倣学習 |
| シミュレーション環境 | robosuite / MuJoCo |
| 本プロジェクトでの学習 | なし。公開済みの重みを使用 |

モデルは、シミュレータから得られる物体の位置・姿勢、ロボット手先の位置・姿勢、グリッパーの状態などを入力として、次の操作を推論します。

**カメラ画像による物体認識は行っていません。** カメラ画像は、観察と動画保存に使用します。

外乱で物体が移動すると、更新された状態情報が次の推論に渡されます。外力の大きさをモデルへ特別な入力として通知する処理はありません。

## 環境・依存関係

付属の環境構築スクリプトは、Python 3.10.22、PyTorch 2.2.2、robomimic 0.3.0、robosuite 1.4.1、MuJoCo 2.3.7を使用する構成です。依存関係は `requirements.lock` と `scripts/bootstrap.sh` を参照してください。

古い公開モデルを別の依存環境で動かしているため、公式論文の環境・性能の厳密な再現を目的とはしていません。

## 実験条件

物体の初期位置を中央に固定し、各条件でseed 1・2を実行します。付属スクリプトは4条件×2シードの計8試行を実行します。

| 条件 | 世界座標での外力 | 外力を加える時間 |
|---|---|---|
| ベースライン | なし | ― |
| 弱い外乱（+X） | (+1.0, 0, 0) N | 開始0.50秒から0.15秒間 |
| 強い外乱（+X） | (+1.5, 0, 0) N | 同上 |
| 逆方向の外乱（−X） | (−1.0, 0, 0) N | 同上 |

外力はMuJoCoの `xfrc_applied` を用いて物体の重心に加えます。物体を瞬間移動させる処理ではありません。また、押し棒などの接触物体はモデル化していません。

X方向はシミュレーションの世界座標における方向であり、画面の左右とは一致しない場合があります。

### 成功判定

物体中心の高さが開始時より **5 cm以上高い状態を、連続1秒以上維持すること**を成功とします。

- 制御周期：20 Hz
- 最大ステップ数：200
- 最大シミュレーション時間：10秒
- 成功条件を満たした時点で、その試行を終了

この判定は高さと保持時間に基づくものです。指と物体の接触状態を直接判定しているわけではありません。

## 実行方法

以下は、WSL2上のUbuntuで、リポジトリの最上位ディレクトリから実行します。

### 1. 必要なシステムパッケージを導入する

```bash
sudo apt update
sudo apt install -y curl git python3-venv build-essential cmake \
  libosmesa6 libgl1 libegl1 libglfw3
```

### 2. Python環境を構築する

```bash
bash scripts/bootstrap.sh
source .venv/bin/activate
```

既存の古いuvでPython 3.10.22を取得できない場合は、使用中のuvを更新してから再実行してください。

### 3. 学習済みモデルを取得する

```bash
python -m lift_tutorial.checkpoint
```

モデルを配布元から取得し、SHA256を照合します。モデルの重みは、このリポジトリには含めません。

### 4. 推論・描画を確認する

```bash
MUJOCO_GL=osmesa python -m lift_tutorial.doctor --device cuda --render
```

結果は `outputs/doctor/` に保存されます。別ウィンドウは開きません。

### 5. 外乱実験を実行する

```bash
bash scripts/run_disturbance.sh cuda
```

実行結果は、新しく作成される `outputs/disturbance-日時-番号/` に保存されます。

CPUで実行する場合は、環境構築時に `bash scripts/bootstrap.sh --cpu` を使用し、診断の `--device cuda` を `--device cpu` に、一括実行の引数 `cuda` を `cpu` に変更してください。

### 6. 結果を確認する

出力先の `comparison.html` をブラウザで開きます。

| ファイル | 内容 |
|---|---|
| `comparison.html` | 条件・シード別の比較表、グラフ、動画 |
| `comparison.csv` | 比較結果の数値 |
| 各条件の `run.json` | 実行条件と環境情報 |
| 各条件の `episodes.csv` | 試行ごとの結果 |
| 各条件の `episodes/` | 時系列データと初期状態 |
| 各条件の `videos/` | 試行ごとのMP4 |
| 各条件の `verification.json` | 記録の整合性の検証結果 |

記録の検証に合格することと、持ち上げに成功することは別です。タスクに失敗した試行も、記録が正常であれば観察対象になります。
